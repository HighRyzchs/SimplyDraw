# Shortcuts

These match the keys handled by the window. A text box, including the text tool editor, keeps the keys it needs.

## Tools

| Key | Tool |
| --- | --- |
| B | Pen |
| E | Eraser |
| S | Select |
| H | Move the page |
| L | Line |
| R | Rectangle |
| O | Ellipse |
| A | Arrow |
| T | Text |
| I | Pick a color from a mark |
| 1–9 | Brush by position in the brush list |

## Drawing

| Input | Action |
| --- | --- |
| Shift while drawing | Straight angles, or a square and a circle |
| Alt with the pen tool | Pick color |
| [ and ] | Smaller or larger brush |
| Space, right mouse, or middle mouse | Pan |
| Wheel | Zoom at the pointer |

## Edit

| Key | Action |
| --- | --- |
| Ctrl+Z | Undo |
| Ctrl+Y or Ctrl+Shift+Z | Redo |
| Ctrl+C | Copy selection |
| Ctrl+X | Cut selection |
| Ctrl+V | Paste selection, or an image if nothing is copied |
| Ctrl+D | Duplicate |
| Ctrl+A | Select all visible, unlocked marks |
| Delete or Backspace | Delete selection |
| Arrow keys | Nudge. Shift nudges farther |
| Escape | Cancel the gesture, clear the selection, close panels |

## File and view

| Key | Action |
| --- | --- |
| Ctrl+N | New |
| Ctrl+O | Open |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as |
| Ctrl+E | Export |
| Ctrl+0 | 100% zoom |
| Ctrl+1 | Fit the drawing |
| Ctrl+Plus / Ctrl+Minus | Zoom in / out |
